# PDF-чек-мейкер

Консольная утилита: читает данные из CSV / JSON, подставляет их в HTML-шаблон и
делает PDF с помощью [WeasyPrint](https://weasyprint.readthedocs.io/). Готовый
файл сохраняется в `output/` и автоматически открывается в системной программе
просмотра.

Поддерживает кириллицу (в репозитории лежит DejaVu Sans), работает на Windows и macOS.

## Быстрый старт

```bash
pip install -r requirements.txt
python main.py
```

> **Windows:** одного `pip install` недостаточно — WeasyPrint нужны нативные
> библиотеки Pango/GObject. Установите
> [GTK3 Runtime](https://github.com/tschoonj/GTK-for-Windows-Runtime-Environment-Installer/releases)
> (подойдёт `gtk3-runtime-...-ts-win64.exe`, установка по умолчанию, галочку
> «Add to PATH» ставить не обязательно). `main.py` находит его сам; если GTK
> стоит в нестандартной папке — укажите её в переменной окружения `GTK_BASEDIR`.
>
> **macOS:** `brew install pango`

## Формат данных

**CSV** — разбирается `pandas` (если его нет — стандартный `csv`). Разделитель
(`,` `;` таб `|`) и кодировка (`utf-8`, `utf-8-sig`, `cp1251`) определяются
автоматически. Один чек = несколько строк с одинаковым `invoice_id`:

```csv
invoice_id,date,customer,seller,inn,manager,item,qty,price,currency
INV-1001,2025-11-03,ИП Смирнов А. В.,ООО Ромашка,7701234567,Козлова Е. И.,Ноутбук ASUS,1,64990.00,RUB
INV-1001,2025-11-03,ИП Смирнов А. В.,ООО Ромашка,7701234567,Козлова Е. И.,Мышь Logitech,2,2490.00,RUB
```

**JSON** — разбирается стандартной библиотекой `json`. Список чеков, позиции
вложенным массивом `items`:

```json
{
  "invoices": [
    {
      "invoice_id": "INV-2001",
      "date": "2026-02-14",
      "customer": "ООО Альфа-Дизайн",
      "seller": "ИП Светлова Н. А.",
      "items": [
        { "item": "UI/UX-макет приложения", "qty": 1, "price": 145000.00 }
      ]
    }
  ]
}
```

Подойдёт и плоский список `[{...}, {...}]`, и одиночный объект.

### Названия колонок

Колонок в шаблоне касаются только четыре «роли» — остальные поля доступны в
шаблоне по своему имени как есть. Распознаются и английские, и русские заголовки
(регистр, пробелы и дефисы не важны):

| Роль | Примеры заголовков |
|---|---|
| номер чека | `invoice_id`, `invoice`, `номер_чека`, `чек`, `номер` |
| дата | `date`, `дата`, `checkdate` |
| покупатель | `customer`, `client`, `покупатель`, `клиент`, `заказчик` |
| продавец | `seller`, `company`, `продавец`, `компания` |
| позиция | `item`, `товар`, `услуга`, `наименование`, `description` |
| количество | `qty`, `quantity`, `кол-во`, `количество` |
| цена | `price`, `цена`, `стоимость за шт` |
| сумма | `sum`, `amount`, `сумма`, `итого` |
| валюта | `currency`, `валюта` (по умолчанию `RUB` → знак `₽`) |

Если суммы позиций нет, она считается как `цена × количество`, а «Итого» — как
сумма по позициям.

## Свои шаблоны

Шаблон — обычный HTML-файл в `templates/` со вставками `{{ имя_поля }}`.
Доступны все поля из данных плюс готовые:

| Плейсхолдер | Что подставит |
|---|---|
| `{{ invoice_id }}` | номер чека |
| `{{ date_fmt }}` | дата в формате `дд.мм.гггг` |
| `{{ customer }}`, `{{ seller }}`, `{{ inn }}` | реквизиты |
| `{{ items_rows }}` | готовые `<tr><td>…</td></tr>` с позициями |
| `{{ items_count }}` | число позиций |
| `{{ total_fmt }}` | сумма вида `1 234,56 ₽` |
| `{{ total_raw }}` | сумма числом, `71260.00` |
| `{{ currency }}`, `{{ currency_sign }}` | код валюты и её знак |
| `{{ source_file }}`, `{{ template_name }}` | откуда и чем нарисовано |
| `{{ generated_at }}` | дата и время генерации |

Правила:

* только двойные фигурные скобки; одинарные `{` в CSS не трогаются, поэтому
  стили можно писать свободно;
* `<title>` шаблона показывается в меню — сделайте его различимым;
* если поля в данных нет, вставка станет пустой, а в консоли будет
  предупреждение — это не ошибка;
* шрифт и `@page` инжектируются в `<head>` **перед** вашими стилями, так что
  любой свой `font-family` в шаблоне имеет приоритет.

### Шрифты

Любой `.ttf` / `.otf`, положенный в `fonts/`, подхватывается автоматически:
вес и стиль угадываются по имени файла (`DejaVuSans-Bold.ttf` → 700).
Имя семейства потом можно использовать в CSS шаблона. Если папка `fonts/`
пустая, используются системные шрифты (DejaVu Sans / Arial) — на Linux и macOS
кириллица есть в них по умолчанию.

## Частые вопросы

**`OSError: cannot load library 'libgobject-2.0-0'`** — не установлен GTK (Windows)
или Pango (macOS). См. «Быстрый старт».

**`GLib-GIO-WARNING ... Unexpectedly, UWP app ... has no verbs`** — безобидный шум
GLib при сканировании реестра Windows. На генерацию PDF не влияет, можно игнорировать.

**Кириллица в PDF превратилась в квадратики/точки** — в `fonts/` нет файла с
кириллическими глифами. Положите туда `DejaVuSans.ttf`.

**Имя файла с русским номером чека** — небезопасные символы заменяются на `_`,
формат имени: `<номер>__<шаблон>__<дата-время>.pdf`.

**`Using fontTools instead of HarfBuzz-Subset`** — предупреждение WeasyPrint о том,
что подмножество шрифта строится медленным путём. Работает корректно.
